# Франшиза CarTaxi — лендинг

Одностраничный лендинг франшизы CarTaxi (эвакуация автомобилей).
Собран по франчайзинговой презентации, оформлен в фирменном стиле cartaxi.io.

**Страница:** https://andreygit5555.github.io/cartaxi-franchise/

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | собранная страница, один файл — картинки и логотип встроены как data-URI |
| `landing.src.html` | исходник с плейсхолдерами, **правки вносить сюда** |
| `build.py` | подставляет ассеты в исходник и пересобирает `index.html` |
| `assets/` | `logo.svg`, `swoosh.svg` (фирменная графика cartaxi.io), `truck.png` (эвакуатор с прозрачным фоном) |

## Пересборка

```bash
python3 build.py
```

Без зависимостей — только стандартная библиотека Python 3.

## Фирменные цвета

Сняты с cartaxi.io:

- `#7900EB` — фиолетовый, акцент
- `#1C273B` — тёмно-синий, текст и тёмные блоки
- `#A4EA4A` — лаймовый, вторичный акцент
- `linear-gradient(92.73deg, #7900EB, #1C273B)` — фирменный градиент
- Шрифты: Montserrat (заголовки) + Noto Sans (текст)

## Интерактив

- калькулятор дохода: заказы в сутки, средний чек, смены, цена техники → выручка, прибыль, окупаемость
- график накопленного денежного потока с точкой выхода в ноль
- разбор среднего чека по долям
- живая лента заказов, реплика личного кабинета
- эвакуатор в первом экране поворачивается за курсором

Цифры в калькуляторе — модельные, из презентации. Не оферта и не гарантия дохода.
